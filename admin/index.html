AgamOffice workspace

Connect your Firebase project.

The admin is built and ready. It needs a free Firebase project for secure Google sign-in, live data and file storage.

  1. 01
    Create the project

    Firebase console → Add project. Enable Authentication → Google, Firestore and Storage.

  2. 02
    Paste the web config

    Project settings → Your apps → Web. Copy the config into assets/js/firebase-config.js and set enabled: true.

  3. 03
    Publish the rules

    Deploy firestore.rules and storage.rules from the site folder (or paste them in the console).

  4. 04
    Add your domain

    Authentication → Settings → Authorized domains: add your Cloudflare Pages domain and agaminterio.com.

Full walkthrough: admin/SETUP.md in the site folder. On localhost the admin opens in demo mode automatically so you can try it first.
